# Эксперименты с моделями классификации

Для задачи прогнозирования оттока клиентов будут протестированы несколько моделей бинарной классификации.

Цель экспериментов — сравнить качество различных алгоритмов на одном и том же наборе данных и определить модель, которая показывает наиболее стабильный результат по основным метрикам.

В качестве основных метрик будут использоваться:

- **F1-score**
- **ROC-AUC**
- **Precision**
- **Recall**
- **PR-AUC**

Дополнительно для оценки устойчивости моделей будет использоваться стратифицированная кросс-валидация.

---

## 1. CatBoostClassifier

`CatBoostClassifier` используется как базовая модель.

Причины выбора:

- хорошо работает с табличными данными;
- умеет напрямую работать с категориальными признаками;
- не требует обязательного One-Hot Encoding;
- поддерживает автоматическую балансировку классов через `auto_class_weights`;
- часто показывает высокое качество на задачах бинарной классификации.

Текущие параметры baseline-модели:

```yaml
iterations: 500
learning_rate: 0.05
depth: 6
loss_function: "Logloss"
eval_metric: "AUC"
auto_class_weights: "Balanced"
random_seed: 42
verbose: 0
